# 方法与数据说明

资料快照为 **2026-10-25**；公开版整理于 **2026-11-02**。这两个日期分别表示资料整理快照和发布处理，不表示课程授课时间，也不保证资料已覆盖其后的变更。

## 数据的四层

| 层次 | 字段 / 关系 | 可支持的判断 |
| --- | --- | --- |
| 概念 | `concepts`、稳定 ID、中英文名和别名 | 找到同一概念或主题组的查询入口 |
| 课程位置 | `occurrences`、阶段、课程代码、位置和要求摘要 | 指向特定版本的章节或目标要求；部分条目仅为先修 / 组合线索 |
| 来源 | `sources`、书名、SHA-256、版次注记 | 识别所用原件；不代表已取得再分发许可或原件可公开下载 |
| 教学资源 | `cards`、原创诊断、活动、答案和接续建议 | 辅助教师备课和观察学习表现；不是官方试题或课程等价判定 |

一条课程位置可关联多个概念。复合主题组与单个概念的关联，不能解释为组内全部子点均适用。概念名称、释义和教学卡的范围也不保证一一对应。

图中 `has_concept` 是学科导航，`has_occurrence` 是概念与位置的关联，`cites` 是来源引用，`supported_by` 是教学卡支持，`requires` 是有向先修建议。`requires` 的源节点是需要先修的概念，目标节点是所需先修；例如阅读为“A requires B”。它不能作为官方统一学习顺序。

## 证据与时间分别处理

“已核正文”“大纲定位已核”等状态沿用资料快照中的记录。来源说明、页码和版次应同时阅读；公开版没有提供原件供读者直接逐页复核。本次发布未重新审计全部内容判断。

`first_seen_eligible` 仅标记可参与所查版本内部早期正文比较的条目；`sequence_rank` 是本库比较顺序，空值表示未知，不能按零处理。高中必修 / 选择性必修册名不能自动换算为某年级某学期。工具先修也不能算作专业概念的首次出现。

`semester_in_plan`、`week_in_plan`、`timing_precision`、`timing_status` 描述示例计划。精确主题行与跨主题周块分别展示；它们都不是实际授课记录。知识点查看器每阶段的图形最多显示四条位置，完整关联以“分阶段查看”和结构化数据为准。

公开版不附带实际授课、人员、班级或学生记录。既不能据此认定学生已掌握，也不能据未提供记录认定教师没有教过。

## 验证边界

`scripts/validate.py` 检查 ID 唯一性、引用完整性、课程阶段、来源哈希格式、图边、笔记文件、CSV 计数、网页内嵌数据一致性、示例查询和公开字段边界。浏览器检查补充验证交互与布局。

这些检查不证明摘要逐句正确、题目适合所有学生、课程完整覆盖、机构认可或课堂效果。暂缺信息保留为待核，不由构建成功补成事实。

## 修改与重建

`data/atlas.json` 和 `exports/graph.json` 是公开数据源。修改关系时同步两个文件，运行 `python scripts/build.py` 生成查看器、Markdown / Canvas 及 CSV，再运行 `python scripts/validate.py`。

`scripts/export_public.py --source <本地知识库目录>` 仅用于维护者从既有格式重新导出。它使用明确字段白名单，不上传输入文件。贡献者无需取得内部原材料即可查询、修正或扩展公开数据。
